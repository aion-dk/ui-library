# Colors

<br />

### Neutrals: prefer the body-opacity utilities

For greys and muted text, reach for the body-opacity family — `text-body-10` … `text-body-90`, `bg-body-10` … `bg-body-90`, plus the `-alt-*` counterparts for inverted surfaces (defined in `src/bootstrap/_body_opacity.scss`). They are derived from `--bs-body-color-rgb`, so one class stays correct in both light and dark mode while still giving 10% emphasis steps.

Prefer them over the alternatives:

- Never `text-muted`. Bootstrap deprecated it in 5.3 (it is now just an alias for `var(--bs-secondary-color)`), and it gives you a single fixed level of muting. Use `text-body-70` — or whichever step reads right — instead.
- The `--bs-gray-{shade}` palette is a **fixed** set of values. It does not follow `data-bs-theme`, so `text-gray-800` becomes dark text on a dark background in dark mode. Use it only for something that must never change with colour mode.
- `bg-secondary` / `text-secondary` are the brand `$secondary` (`#eeeeee`), a brand colour rather than a surface token — also fixed.
- `text-body-secondary` / `bg-body-tertiary` do follow colour mode, but they are three coarse steps; `text-body-70` says "muted" directly and stays adjustable.

<br />

### How the body-opacity utilities work

Every step is generated from `--bs-body-color-rgb`, which Bootstrap redefines under `data-bs-theme`, so the same class resolves differently per mode. In light mode `--bs-body-color-rgb` is `33, 37, 41` (near-black) while `--bs-body-color-alt-rgb` is `222, 226, 230` (near-white); in dark mode the two swap. The `-alt-*` family is therefore built from the **opposite** mode's colour, which is what makes it useful for inverted surfaces.

- `.text-body-10` … `.text-body-90` — the current mode's body colour at 10–90%. Use for text emphasis: `text-body-70` for muted copy, `text-body-90` for near-full strength.
- `.bg-body-10` … `.bg-body-90` — the _opposite_ mode's body colour at 10–90%. Use for subtle surfaces that follow the mode: table headers, cards, wells.
- `.text-body-alt-10` … `.text-body-alt-90` — the _opposite_ mode's body colour. Use for text sitting on an inverted surface.
- `.bg-body-alt-10` … `.bg-body-alt-90` — the current mode's body colour. Use for deliberately inverted surfaces.
- `.text-body-alt` / `.bg-body-alt` — full-strength inverted text colour and background.
- `.text-body-secondary-alt` / `.bg-body-secondary-alt` / `.text-body-tertiary-alt` / `.bg-body-tertiary-alt` — inverted equivalents of Bootstrap's secondary and tertiary tokens.

Steps go in tens from 10 to 90 — for full strength use plain `text-body` / `bg-body`.

The rule of thumb is to keep a surface and its text in the same family. On a normal surface pair `bg-body-*` with `text-body-*`; on an inverted one pair `bg-body-alt-*` with `text-body-alt-*`:

### Brand palette

These come from `src/bootstrap/bootstrap.customized.scss` and are merged into `$theme-colors`, so each one generates the usual Bootstrap utilities — `.text-{name}`, `.bg-{name}`, `.border-{name}`, `.btn-{name}` — plus a `.bg-{name}-faded` variant (the colour mixed 20% into white) and a `.pulse-shadow-{name}` animation.

Note that these are **fixed brand values**: they do not react to `data-bs-theme`. Use them for brand identity, not for surfaces or body copy — those belong to the body-opacity utilities above.

### Semantic colors

Use Bootstrap's utility classes (`success`, `info`, `warning`, `danger`) and their `-faded` / `bg-*-subtle` variants rather than hard-coded values, so they keep following the colour mode.
